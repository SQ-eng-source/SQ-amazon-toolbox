# 月度回款计算器 · 使用说明

## 它是干嘛的

回答一个让很多新卖家懵的问题：**后台报表说我这月赚了 3 万，为什么账户里没钱？**

因为"报表利润"和"到账的钱"是两回事。亚马逊会先扣掉佣金、配送费、仓储、广告、退货，剩下的才结给你，而且还要压一个账期。

这个工具就是把**从销售额到你银行卡**这条路上的每一笔扣款列清楚。

## 三步用起来

1. 打开工具：[月度回款计算器](../tools/payout.html)
2. 填一个月的数：

| 字段 | 从哪来 |
| --- | --- |
| 月销售额（USD） | 业务报告或结算页 |
| 平台佣金（%） | 一般 15% |
| FBA 配送费合计 | 结算页的费用汇总 |
| 仓储费 + 长期仓储 | 库存费用报表 |
| 广告费 | 广告报表当月总花费 |
| 退货/赔付等杂项扣款 | 结算页"其他"项目 |
| 产品采购已付成本 | 这个月你实际付给工厂的钱 |
| 回款周期（天） | 一般填 14 |

3. 右边出结果。

## 结果怎么看

| 结果 | 含义 |
| --- | --- |
| 本月预计回款（未扣采购） | 亚马逊这个月会打给你的钱 |
| 所有扣款合计 / 扣款占销售额 | 平台到底拿走了多少，这个比例很值得记住 |
| **经营现金流（扣采购后）** | 你真正能拿来周转的钱 ← 最该看的一行 |
| 在途冻结资金（约） | 压在账期里还没到手的钱 |

**在途冻结 = 回款周期 ÷ 30 × 月销售额**。生意越大，这部分压得越多——很多"越做越穷"就是它造成的。

## 两个要注意的地方

- **现金流 ≠ 利润**。现金流被账期和采购节奏影响，某个月现金流为负不一定是亏，可能是备货花了钱。但连续几个月为负，一定要查。
- **扩量前先算冻结**。销量翻倍，压在账期的钱也翻倍，先确认账户扛得住。

## 常见问题

**Q：为什么"本月预计回款"比销售额少那么多？**
佣金 15% + FBA 配送费 + 广告 + 仓储，加起来经常吃掉 45%–55%。这不是异常。

**Q：采购成本要填这个月付的还是这批货的？**
填**这个月实际付出去的**，因为工具算的是现金流，不是会计利润。

---

**一句话**：看报表利润决定要不要继续做，看现金流决定这个月发得出工资吗。
