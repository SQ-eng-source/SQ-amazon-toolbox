需求洞察（搜索词聚类）· 使用说明

→ 直接打开工具

拿到一堆搜索词，别急着塞进标题。先回答一个问题：用户到底在找什么？ 这个工具把词按六个维度聚类，告诉你哪个维度的需求最重、哪里还有没人占的空位。

这个工具解决什么问题

写 Listing 最常见的错：把自己觉得厉害的卖点当主打，但买家搜的词里根本没人提这个维度。

比如一批"dog bowl"的搜索词里，"slow feeder""raised""stainless""for large dogs"各占一块——功能、规格、材质、人群都真实存在，但权重完全不同。主标题和五点第一句该打哪个维度，词表说了算，不是你说了算。

工具做的事：

  1. 按品类核心词把词分组。
  2. 把修饰词归到六个维度：场景 / 人群 / 功能 / 材质 / 规格 / 价值。
  3. 算每个维度的需求构成占比。
  4. 找空位：某个维度有真实搜索量，但主流竞品都没覆盖的词。

怎么用

  1. 打开工具台 → 板块 02 市场洞察 → 需求洞察。
  2. 把搜索词和量一起贴进数据框（一行一词一带量；量可以是搜索量、SQP 成交量或词频，口径一致就行）。来源：ABA 词表、商探关键词导出、SQP 搜索词报告都行。
  3. 出结果：分组 → 六维度构成 → 空位洞察。

结果怎么看

  • 需求最重的维度 = 你的主打卖点：标题核心词后面第一个修饰词、五点第一句、主图场景，都优先放它。
  • 第二、第三维度：塞进五点和 Search Terms，别挤标题。
  • 空位洞察里的词：有量没人占——这就是你的差异位。可能是没人做的场景，也可能是大家忽略的人群。先确认不是坑（比如是停售品类的残留词）再押。

两个要注意的地方

  • 词量至少几十个才有聚类意义，十来个词看构成纯属抽样噪音。
  • 同义词先合并：dog bowl 和 dog bowls 在你贴的表里是一回事就手动合成一行，量相加，占比才准。

一句话：需求最重的维度是主打卖点，空位的维度是差异位——标题五点都从这张构成表出发。
