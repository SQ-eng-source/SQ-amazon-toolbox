# 广告出价计算器 · 使用说明

## 它是干嘛的

打广告时最常见的问题是：**这个词我该出多少钱？**

出低了没曝光，出高了亏钱。这个工具用你的成本和转化率，算出**这个词最高能出到多少 CPC**。

## 三步用起来

1. 打开工具：[广告出价计算器](../tools/bid.html)
2. 填五个数：

| 字段 | 填什么 |
| --- | --- |
| 售价（USD） | — |
| 单件总成本（产品+头程+FBA+佣金） | 四样加起来 |
| 目标广告 ACoS（%） | 保本 = 毛利率；冲排名可放宽 |
| 该词当前转化率 CVR（%） | 这个词的点击→下单比例，没有就先按类目均值 |
| （可选）当前实际 CPC | 填了会直接判断能不能跑 |

3. 看结果。

## 结果怎么看

核心公式：

> **最高可承受 CPC = 售价 × 目标 ACoS × 转化率**

举例：售价 $25，目标 ACoS 30%，CVR 10%
→ 最高 CPC = 25 × 0.3 × 0.1 = **$0.75**

| 结果 | 含义 |
| --- | --- |
| 最高可承受 CPC | 超过这个价，这个词大概率亏 |
| 目标获客成本 | 每单广告费的天花板 |
| 单件毛利 | 不打广告时一单赚多少 |
| 按当前 CPC 的盈亏判断 | 填了实际 CPC 才有，直接告诉你"可以跑 / 建议降价" |

## 两个要注意的地方

- **CVR 是变数最大的输入**。同一个词，旺季和淡季、有券和没券，转化率能差一倍。填保守值，宁可少出价。
- **千万别用"行业平均 CPC"当出价**。别人能出 $1.5 是因为他转化率高或者毛利高，你照抄就是亏。

## 常见问题

**Q：目标 ACoS 该填多少？**
新品冲排名可以填到保本线以上（比如毛利率 35% 就填 45%），但要有期限。稳定期用保本线或略低。

**Q：算出来的最高 CPC 比建议竞价低很多怎么办？**
说明这个词烧不起。两个方向：提高转化率（改主图/价格），或者去打更精准的长尾词。

---

**一句话**：出价不是猜的，是拿"售价 × 目标ACoS × 转化率"算出来的上限。
