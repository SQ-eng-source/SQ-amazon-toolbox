口径说明（与你表格公式一致）：
· 税后净售价 = 售价 ÷ (1 + 税率)；税费 = 售价 − 净售价
· 单次退货成本 = 采购成本 + 头程 + FBA配送费 + 佣金×20% + 弃置费（按你表内备注口径，比例可改）
· 总成本 = 采购 + 佣金 + 税费 + FBA + 头程 + 仓储 + 均摊退货 + 其它
· 利润 = 销售额 − 总成本；扣广告利润 = 利润 − 净售价×广告%
· 利润率 = 利润 ÷ 税后净售价（VAT 不属于你的收入，不参与分母；扣广告利润率同口径）
