选品机会评分

四道闸门：A 利润结构（自动算）→ B 需求 → C 竞争 → D 风险与资源。结论只有五种：GO（押注）/ TEST（小步验证）/ FIX（先修再上）/ HOLD（资源不到位）/ KILL（放弃）。顺序不可跳——A 不过就不必看后面：不投广告都不赚钱的品，流量再好也是亏。门禁口径来自孵化模型，分数是排序工具不是预言。

① A · 利润结构（自动打分）不投广告能赚钱吗

② B/C/D · 打分题 0-10 分，凭证据打，没证据按 0 分

B 需求 总量、趋势、意图清晰度

主词搜索量处于健康区间（1 万～30 万，太小吃不饱、太大打不动）
趋势：过去 12 个月同比不跌（用「市场流量趋势」验证过）
搜索意图清晰（搜这个词的人明确知道要什么，不是研究型浏览词）

C 竞争 流量缝隙、头部强度、差异化

目标词有 A 档缝隙（Top3 点击份额 < 40%，ABA 验证过；没验证按 0 分）
头部竞品评分 ≤ 4.4 或评论数 < 2000 的至少 3 家（打得动）
有可证伪的差异点假设（竞品差评最高频的痛点，我能用产品力解决）
价格带我进得去（目标价落在竞品价格带内，不用打穿底线）

D 风险与资源 合规、库存、资金、精力

合规干净（无认证缺口、无专利/商标风险、非限制类目）
资金到位（首单 + 90 天广告预算不伤现金流）
供应链稳（打样周期、返单能力、旺季不涨价承诺）
精力够（同时推进的新品 ≤ 2 个，这个能排进前二）
