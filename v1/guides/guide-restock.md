# FBA 补货计算器 · 使用说明

## 它是干嘛的

回答一个问题：**现在我该不该补货？补多少？**

算的是"补货点"——库存掉到这个数，就必须下单了，否则等货到的这段时间会断货。
断货的代价比压货大得多：排名掉下去，回来要重新推。

## 三步用起来

1. 打开工具：[FBA 补货计算器](../tools/restock.html)
2. 填单款数据（左边"① 单款试算"）：

| 字段 | 填什么 |
| --- | --- |
| SKU / 产品名 | 一眼能认出来的名字，如 `B0DK13MV1R 泳镜 白+粉` |
| 站点 | UK / DE / US / CA |
| 日均销量（件/天） | 最近 30 天日均，**别用大促那几天** |
| FBA 在库 / 在途 | 后台库存页的"可售"和"在途/入库中" |
| 生产周期（天） | 工厂做完要几天 |
| 头程+上架（天） | 海运或空运到能卖，一共几天 |
| 安全库存天数 | 建议 15–30，怕断货就往上加 |

3. 点「💾 保存到看板」，这款就进了下面的「③ SKU 补货看板」，可以一路看全部 SKU。

## 结果怎么看

补货点公式是：

> **补货点 = 日均销量 ×（生产 + 头程 + 上架天数）+ 安全库存天数 × 日均销量**

换算成人话：**从现在下单到能卖，这段时间会卖掉多少，再加一点安全垫。**

判断标准看"可售天数"：

| 可售天数 | 该做什么 |
| --- | --- |
| 低于（生产 + 头程） | **危险**，已经来不及了，赶紧空运或调货 |
| 刚过补货点 | 马上安排下单 |
| 明显高于补货点 | 还够，观察即可 |

## 云同步（换电脑 / 换浏览器必看）

数据默认存在浏览器本地，换设备就看不到。点「☁ 云同步」，填仓库、分支/文件、GitHub 令牌，就能存到云端。

**三个按钮的区别**：

- **仅下载云端** / **仅上传本地**：覆盖式，点之前会弹确认框，**会把对方的数据盖掉**
- **合并同步**：只新增和更新，**永远不会减少记录** ← 不确定时一律用它

## 两个要注意的地方

- **日均销量用错，全盘都错**。旺季、大促、断货那几天的数据要剔掉，用平稳期的 14–30 天平均。
- **头程时间宁多勿少**。报关、清关、排柜都容易卡，多算 5 天比少算 5 天安全。

## 常见问题

**Q：在途算不算库存？**
算，所以有单独一栏。工具看的是"在库 + 在途"能不能撑到下一批货到。

**Q：多个 SKU 怎么管？**
每款单独填一次、点保存，看板会累积。导出 CSV 可以发给采购。

---

**一句话**：补货点 = 到货这段时间会卖掉的量 + 安全垫，低于它就该下单。
