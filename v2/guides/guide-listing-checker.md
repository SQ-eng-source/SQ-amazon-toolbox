# Listing 字符与合规检查器 · 使用说明

## 它是干嘛的

上传 Listing 之前，先过一遍体检：**字符超没超、有没有违规词、全大写会不会被压权重。**

这些错误在后台不一定报错，但会悄悄吃掉你的曝光。

## 三步用起来

1. 打开工具：[Listing 字符与合规检查器](../tools/listing-checker.html)
2. 把**标题**粘进上面的大框，**五点描述**粘进下面的框（**一行一条**，别把五条连成一段）。
3. 右边自动出检查结果，边打字边更新。

## 结果怎么看

| 检查项 | 标准 |
| --- | --- |
| 标题字符数 | 上限一般 200，**部分类目 150** |
| 接近上限（超过 92%） | 会有黄色提示，容易被截断 |
| 五点条数与最长条 | 建议 5 条，单条太长手机端会折叠 |
| 全大写词（4 个字母以上） | 亚马逊不鼓励，可能被抑制显示 |
| 疑似违规/营销词 | 红色，必须改 |
| 装饰符 `【】[]{}` 、连续感叹号 | 黄色，官方不鼓励非字母数字符号 |

**标题词数 / 平均字符长度**也一并给出，太长可以拆短句。

## 工具会查的违规词

`best`、`#1`、`no.1`、`number one`、`free shipping`、`free gift`、`guarantee`、`cheapest`、`hot sale`、`100%`、`top rated`、`world's`、`satisfaction`、`money back`、`wholesale`、`promotion`

这些词属于"夸大宣传 / 促销承诺"，轻则被删，重则影响账户健康。

## 两个要注意的地方

- **不同类目字符上限不一样**。工具按 200 算，如果后台提示 150，以**后台实际上传时的提示**为准。
- **过了检查 ≠ 排名好**。这个工具只查合规和长度，不查关键词覆盖和可读性。关键词那块用「标题规范」工具。

## 常见问题

**Q：五点一定要写满 500 字符吗？**
不用。能说清卖点、手机端不折叠就好。五条超过 5 条会被标红。

**Q：`100%` 也不行？**
不行，属于绝对化表述。可以改成 `fully`、`complete`。

**Q：检查完还要做什么？**
再用「标题规范」过一遍关键词结构，最后人工读一遍——**像买家一样读，看能不能三秒懂**。
